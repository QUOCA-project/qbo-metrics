# Calculation of QBO metrics

This repository provides code for calculating diagnostic metrics of the Quasi-Biennial Oscillation (QBO) using separate methodologies. 
Currently, an EOF method following DallaSanta et al. (2021) and a composite methodology have been implemented.

To use the code, clone the repo and follow the documentation in `docs/docs.pdf`. Example code has been provided in `example.py` along with a minimal data file `example_data.nc`.

Fixes and additions to the code are welcome; please submit a pull request!
